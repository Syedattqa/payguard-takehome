# AI Usage Disclosure

## Tools used

| Tool | Role |
|---|---|
| **Claude (Anthropic), Cowork mode** | Coding and writing assistant for the whole submission |
| **OpenAI `gpt-6-luna`** | The LLM *inside* the Part B pipeline (the component being evaluated) |
| **OpenAI `gpt-6-sol`** | LLM-as-judge that produced the Part B evaluation labels |

## What I did myself

- Read and scoped the brief; set up the project structure, virtual environment and data download.
- Wrote the first exploration scripts (`part_a_fraud/explore.py`, `temporal_analysis.py`), including
  the decision to use a **time-ordered 70/15/15 split** rather than a random one, which the final
  notebook keeps.
- Made the main project decisions: Part A as a Colab notebook, Part B as a batch script, OpenAI as the
  provider, and the memo on complaint triage.
- Ran the full Part B pipeline on my machine with my own API key: data fetch, 400-complaint triage run,
  adversarial run, judge labelling, evaluation and cost report.
- **Chose to use an LLM judge instead of hand-labelling the evaluation set.** I started hand-labelling
  with `label_tool.py` (1 complaint labelled) and then decided a blind judge from a stronger model was
  a better use of the time available. This is a deliberate trade-off, and its limitation (labels
  measure model-vs-model agreement, not verified truth) is stated in the Part B README.
- Worked through the Part A notebook with Claude section by section to understand each decision.

## What the AI produced

Also switched the OpenAI default model after checking current model names and prices. |
| Documents | Drafted the READMEs, the Part C memo and this file. |

**Rough share of code produced by AI: ~90%.** My direct code contribution was the initial exploration
scripts and the time-split design; my other contributions were decisions, running the pipeline and
interpreting the results.

## Model outputs used as data

- All Part B triage records (`outputs/predictions_gpt-6-luna.jsonl`) are model output, by design.
- The 80 evaluation labels (`data/labels_judge.csv`) were generated by `gpt-6-sol`, labelling blind
  (it never saw the triage output). They are not human labels.
